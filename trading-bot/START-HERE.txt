========================================
 ربات معامله‌گر — از اینجا شروع کنید
========================================

اگر عجله دارید (۳۰ ثانیه):
  ۱) این پوشه را از حالت zip خارج کنید (Extract / Unzip).
  ۲) ویندوز: روی start.bat دوبار کلیک کنید.
     مک:   ترمینال را در همین پوشه باز کنید و بزنید:  bash start.sh
  ۳) به سؤال‌های فارسی جواب بدهید. حالت «تمرینی» را انتخاب کنید.
     در حالت تمرینی نیازی به کلید API نیست و پول واقعی در خطر نیست.

برای خواندن راهنمای کامل:
  docs/QUICKSTART-FA.md      ← گام‌به‌گام، بدون دانش فنی
  README.md                  ← توضیح فنی و تنظیمات

خلاصه‌ی دستورها (در ترمینال، داخل همین پوشه):
  python setup_wizard.py     ساخت تنظیمات با چند سؤال
  python -m trader check     بررسی نهایی (هیچ سفارشی ثبت نمی‌شود)
  python -m trader once      یک تصمیم/معامله‌ی آزمایشی
  python -m trader run       اجرای مداوم
  python -m trader status    وضعیت حساب و موقعیت
  python -m trader report    آخرین معاملات و تصمیم‌ها
  python -m trader panic     توقف اضطراری (یا اجرای stop.bat)
  python scripts/demo_offline.py   نمایش نمونه‌ی کارکرد، بدون اینترنت

مهم:
  • فایل .env شامل کلید شماست؛ آن را برای هیچ‌کس نفرستید و در گیت نگذارید.
  • کلید API را با مجوز Read + Trade بسازید و Withdrawal را خاموش بگذارید.
  • این ابزار تضمین سود نمی‌دهد؛ هدفش محدود کردن ضرر و تصمیم منظم است.
