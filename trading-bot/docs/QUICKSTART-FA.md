# راهنمای صفر تا صد برای کسی که با API کار نکرده است

این راهنما فرض می‌کند **هیچ** دانش فنی ندارید. هر دستور را می‌شود کپی کرد.
کل زمان لازم: حدود ۱۵ دقیقه برای شروع تمرینی.

---

## ۰) سه چیز را از اول بدانید (۳۰ ثانیه)

1. **هیچ رباتی نمی‌تواند تضمین کند ضرر نکنید.** کاری که این ربات می‌کند این است
   که تصمیم‌هایش را قاعده‌مند و حدّاکثر زیانش را از قبل محدود می‌کند.
2. **پول از حساب صرافی شما خارج نمی‌شود.** ربات فقط سفارش خرید/فروش می‌گذارد؛
   دارایی در همان کیف پول صرافی می‌ماند. کد ربات هیچ راهی برای برداشت ندارد و
   کلید API هم باید بدون مجوز برداشت ساخته شود.
3. **معامله‌ی زیاد ≠ سود بیشتر.** در ایران کارمزد هر معامله حدود ۰.۴٪ است؛
   یعنی هر خرید+فروش ≈ ۰.۸٪ هزینه. اگر روزی ۱۰ بار معامله کنید، حدود ۸٪ از
   سرمایه صرف کارمزد می‌شود. به همین دلیل پیش‌فرض‌ها محافظه‌کارانه‌اند.

---

## ۱) مسیر سریع: بدون کلید API، بدون پول واقعی (۵ دقیقه)

فقط می‌خواهید ببینید ربات چه می‌کند؟ این مسیر هیچ ریسکی ندارد.

1. **پایتون را نصب کنید** (اگر ندارید):
   - ویندوز: از <https://www.python.org/downloads/> نسخه 3.10 یا بالاتر؛ هنگام نصب
     تیک **Add Python to PATH** را بزنید.
   - مک: پایتون معمولاً نصب است؛ اگر نبود از همان سایت.
2. **پوشه‌ی ربات را باز کنید**: پوشه‌ی `trading-bot` را روی کامپیوتر کپی کنید.
3. **اجرا:**
   - ویندوز: روی `start.bat` دوبار کلیک کنید.
   - مک/لینوکس: ترمینال را در همان پوشه باز کنید و بزنید:
     ```bash
     bash start.sh
     ```
4. اولین بار، چند سؤال ساده می‌پرسد (فارسی):
   ```
   ۱) از کدام صرافی استفاده می‌کنید؟  →  1 (نوبیتکس)
   ۲) نام دارایی؟                      →  Enter (BTCIRT)
   ۳) حالت اجرا؟                       →  1 (تمرینی)
   ۵) میزان محافظه‌کاری؟                →  1 (محافظه‌کار)
   ۶) سرمایه‌ی فرضی؟                   →  Enter (۱۰ میلیون تومان)
   ۷) گزارش تلگرام؟                    →  n
   ```
5. تمام. ربات شروع می‌کند. خروجی شبیه این است:
   ```
   ✅ تنظیمات: حالت paper | nobitex | BTCIRT | حداکثر موقعیت 3.0%
   • قیمت بالای EMA سریع؛ EMA20 بالای EMA50؛ ... 
   💬 خرید انجام شد — BTCIRT
   ```
6. **برای توقف:** `Ctrl + C` در همان پنجره. برای توقف فوری از هر جای دیگر:
   `start.bat` را ببندید و `stop.bat` را اجرا کنید (در مک: `bash stop.sh`).

> در این حالت، «پول» فرضی است و هیچ سفارشی به صرافی نمی‌رود. داده‌ی قیمت از
> بازار واقعی خوانده می‌شود (اگر اینترنت قطع باشد، ربات فقط خطا نشان می‌دهد و
> هیچ کاری نمی‌کند).

---

## ۲) مسیر واقعی: ساختن کلید API در نوبیتکس (قدم به قدم)

> اگر قبلاً کلیدی ساخته‌اید و جایی منتشر شده (چت، عکس، تیکت) → **اول حذفش کنید**
> و از نو بسازید.

1. وارد پنل نوبیتکس شوید → **تنظیمات** → **API** (یا «مدیریت API»).
2. روی **ساخت کلید جدید / Create API Key** بزنید.
3. نامی مثل `bot` بدهید.
4. مجوزها را **دقیقاً** این‌طور تنظیم کنید:

   | مجوز | وضعیت |
   |---|---|
   | Read / مشاهده | ✅ روشن |
   | Trade / معامله | ✅ روشن |
   | Withdrawal / برداشت | ❌ **خاموش** |
   | Futures / اهرم | ❌ خاموش |

5. کلید را بسازید. صرافی **یک بار** دو مقدار نشان می‌دهد:
   - `API Key` / `Token`
   - `API Secret`
6. آن‌ها را کپی کنید و **همان‌جا** در جایی امن بگذارید (مثلاً یک فایل متنی روی
   کامپیوتر خودتان). در تلگرام/واتساپ/ایمیل نفرستید.

> این ربات برای نوبیتکس فقط به **Token** نیاز دارد. `API Secret` را می‌توانید
> نگه دارید، ولی ربات از آن استفاده نمی‌کند.

---

## ۳) وصل کردن کلید به ربات

1. دستیار راه‌اندازی را دوباره اجرا کنید:
   ```bash
   python setup_wizard.py
   ```
2. پاسخ‌ها:
   ```
   ۱) صرافی؟          → 1 (نوبیتکس)
   ۲) نماد؟           → Enter
   ۳) حالت اجرا؟      → 2 (واقعی)   ← فقط اگر مطمئنید
   ۴) کلید API        → Paste کنید (هنگام تایپ چیزی دیده نمی‌شود؛ طبیعی است)
   ۵) محافظه‌کاری      → 1
   ۷) تلگرام؟         → n  (یا y برای گزارش لحظه‌ای)
   تایپ عبارت تأیید:  → I-UNDERSTAND-THE-RISK
   ```
3. بررسی نهایی و یک معامله‌ی آزمایشی:
   ```bash
   python -m trader check     # همه‌ی خطوط باید ✅ یا ⚠️ غیرمسدودکننده باشند
   python -m trader status    # موجودی واقعی حساب را نشان می‌دهد
   python -m trader once      # یک چرخه؛ اگر سیگنال نبود، «HOLD» می‌گوید
   python -m trader run       # اجرای مداوم
   ```

**توصیه‌ی جدی:** حتی اگر الآن کلید دارید، اول یک هفته با حالت تمرینی (`paper`)
اجرا کنید و `python -m trader report` را ببینید. بعد با مبلغی که از دست دادنش
برای شما مهم نیست شروع کنید (مثلاً ۵–۱۰٪ سرمایه‌تان) و `MAX_POSITION_PCT` را ۱–۲
بگذارید.

## ۴) اجرای ۲۴ ساعته (اگر کامپیوترتان خاموش شود، ربات هم می‌خوابد)

ربات باید جایی اجرا شود که همیشه روشن و به اینترنت وصل باشد:

| گزینه | هزینه | مناسب چه کسی |
|---|---|---|
| کامپیوتر/لپ‌تاپ خودتان | صفر | فقط برای تمرین؛ با خواب رفتن قطع می‌شود |
| VPS (سرور مجازی) | حدود ۵–۷ دلار در ماه | اجرای واقعی ۲۴/۷ |

خرید VPS (نمونه با Hetzner/Contabo/آروان — هرکدام که ساده‌تر بود):

1. یک سرور Ubuntu 22.04 با ۱ گیگ رم بگیرید.
2. آدرس IP و رمز root را از ایمیل/پنل بگیرید.
3. با برنامه‌ای مثل **Termius** یا **PuTTY** به سرور وصل شوید.
4. این دستورها را کپی-پیست کنید:
   ```bash
   sudo apt update && sudo apt install -y python3 python3-venv git
   sudo adduser --system --group trader
   sudo mkdir -p /opt/danesh-trader && sudo chown trader:trader /opt/danesh-trader
   # پوشه‌ی trading-bot را با FileZilla/WinSCP به /opt/danesh-trader آپلود کنید
   cd /opt/danesh-trader
   sudo -u trader python3 -m venv .venv
   sudo -u trader .venv/bin/pip install -r requirements.txt
   sudo -u trader python setup_wizard.py       # کلید را اینجا وارد کنید
   sudo cp deploy/trader.service /etc/systemd/system/
   sudo systemctl daemon-reload
   sudo systemctl enable --now trader
   ```
5. دیدن گزارش زنده:
   ```bash
   sudo journalctl -u trader -f
   ```
6. توقف فوری:
   ```bash
   sudo -u trader /opt/danesh-trader/.venv/bin/python -m trader panic
   ```

> اگر آپلود فایل برایتان سخت است، از همین راهنما به کسی که کمی با لینوکس آشناست
> کمک بگیرید؛ فقط همین ۸ خط است.

## ۵) چه انتظاری منطقی است؟ (بدون تعارف)

- **حد ضرر و سقف ضرر روزانه وجود دارد**، اما ضرر صفر وجود ندارد. اگر کسی بگوید
  «ربات بدون ضرر»، دارد اشتباه می‌کند یا دارد چیزی می‌فروشد.
- با سرمایه‌ی کوچک و کارمزد ۰.۴٪، هدف واقع‌بینانه «حفظ سرمایه + سود چند درصدی در
  ماه» است، نه دو برابر کردن پول در یک هفته.
- ربات هر ۵ دقیقه یک بار نگاه می‌کند؛ اگر بازار در جهت مخالف بپرد، حد ضرر جلوی
  زیان بزرگ را می‌گیرد، ولی همان حد ضرر هم یعنی ضرر کوچک واقعی.
- «چند معامله در روز» کارمزد را چند برابر می‌کند. پروفایل «فعال» را فقط برای
  تمرین بگذارید؛ با پول واقعی، پروفایل ۱ (محافظه‌کار) منطقی‌تر است.

اعداد همین حالا در خروجی `python -m trader check` زیر عنوان
«اقتصاد معامله» نمایش داده می‌شوند: کارمزد رفت‌وبرگشت، سود خالص هر معامله‌ی
برنده، و **حداقل درصد برد لازم** برای سربه‌سر شدن.

## ۶) اگر گیر کردید

| پیام | معنی | کار |
|---|---|---|
| `python: command not found` | پایتون نصب نیست | از python.org نصب کنید و PATH را تیک بزنید |
| `HTTP 401` / `HTTP 403` | کلید اشتباه یا بدون مجوز معامله | کلید را با Read+Trade بازسازی کنید |
| `داده‌ی کندل کافی نیست` | اینترنت/دسترسی به صرافی مشکل دارد | VPN/شبکه را بررسی کنید؛ `python -m trader check` |
| `اسپرد بازار ...` | بازار بی‌عمق است | طبیعی است؛ ربات صبر می‌کند |
| `سفارش در مهلت مقرر پر نشد` | قیمت جابه‌جا شد | سفارش لغو می‌شود؛ چیز خاصی لازم نیست |
| گزارش تلگرام نمی‌آید | Chat ID اشتباه | به ربات خودتان پیام بدهید؛ ID را از `@userinfobot` بگیرید |
| دو بار اجرا شده | فایل `state/trader.lock` | نمونه‌ی قبلی را ببندید؛ فایل را پاک کنید |

هر زمان خواستید همه‌چیز را از صفر تنظیم کنید: `python setup_wizard.py` را دوباره
اجرا کنید (نسخه‌ی قبلی `.env` به‌صورت پشتیبان ذخیره می‌شود).
