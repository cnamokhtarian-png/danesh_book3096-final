# استراتژی و قواعد ریسک

## منطق تصمیم

هر چرخه، از کندل‌های `CANDLE_RESOLUTION` (پیش‌فرض ۵ دقیقه) و `CANDLE_LOOKBACK`
(پیش‌فرض ۲۴۰ کندل ≈ ۲۰ ساعت) استفاده می‌شود:

| اندیکاتور | نقش |
|---|---|
| EMA ۲۰ / EMA ۵۰ | جهت کوتاه‌مدت و میان‌مدت |
| EMA ۲۰۰ | فیلتر روند بلندمدت (اگر داده کافی نباشد، غیرفعال) |
| RSI ۱۴ | جلوگیری از خرید در اشباع خرید و تشخیص برگشت |
| ATR ۱۴ | نوسان؛ هم فیلتر ورود و هم تنظیم حد ضرر |
| نسبت حجم | تأیید حرکت (کندل آخر نسبت به میانگین ۲۰ کندل) |

### سیگنال خرید

همه‌ی موارد باید برقرار باشند:

1. قیمت > EMA سریع
2. EMA سریع > EMA میانی
3. قیمت > EMA بلندمدت (اگر موجود باشد)
4. `45 ≤ RSI < 78`
5. نسبت حجم ≥ `min_volume_ratio` (۰.۵)
6. `ATR% ≤ max_atr_pct` (۶٪)
7. بازار «بدون روند» نباشد (فاصله‌ی قیمت و EMAها > ۰.۱۵٪)

### سیگنال فروش

- قیمت زیر EMA میانی، یا
- `RSI ≥ 78` (اشباع خرید) یا `RSI < 30` (شکست نزولی)، یا
- دو شرط نزولی از مجموعه‌ی EMA/RSI.

### صبر (HOLD)

داده‌ی ناکافی، بازار خنثی، نوسان بیش از حد، یا سیگنال‌های متناقض.

### حد ضرر و حد سود

پیش‌فرض: حد ضرر ۲٪ و حد سود ۴٪ نسبت به قیمت میانگین خرید. اگر ATR بزرگ باشد،
حد ضرر تا `۱.۵ × ATR%` باز می‌شود (سقف: ۲.۵ برابر مقدار پایه) تا با نویز عادی
بازار فعال نشود و حد سود حداقل `۱.۸ ×` حد ضرر می‌ماند.

بررسی حد ضرر/سود **پیش از** هر سیگنال دیگری انجام می‌شود؛ حتی اگر هوش مصنوعی
بگوید «صبر کن»، خروج ریسک اجرا می‌شود.

## ترتیب لایه‌ها (مهم)

```
حد ضرر/سود  →  قواعد تکنیکال  →  AI (تأیید/وتو)  →  ریسک (اندازه و سقف)  →  سفارش limit
```

هیچ لایه‌ای نمی‌تواند لایه‌ی سمت راست را دور بزند. مدل هوش مصنوعی هرگز حجم سفارش
را تعیین نمی‌کند.

## اندازه‌گذاری

```
حجم پیشنهادی = min( نقدینگی آزاد ، سهمMAX_POSITION از دارایی کل ، فضای باقی‌مانده تا MAX_TOTAL )
```

اگر نتیجه کمتر از `MIN_TRADE_QUOTE` باشد، معامله انجام نمی‌شود (سفارش‌های کوچک
بی‌صرفه‌اند و صرافی رد می‌کند).

## توقف‌ها

| شرط | اثر |
|---|---|
| افت روزانه از `MAX_DAILY_LOSS_PCT` | خرید جدید متوقف؛ فروش/خروج آزاد |
| `MAX_TRADES_PER_DAY` | توقف خرید تا روز بعد |
| `COOLDOWN_MINUTES` | فاصله بین معاملات |
| اسپرد > `MAX_SPREAD_PCT` | توقف خرید (فروش برای خروج مجاز) |
| فایل `state/STOP` | توقف کامل چرخه |
| ۱۰ خطای شبکه‌ی پیاپی | خروج امن با هشدار |

## تنظیم برای سرمایه‌ی کوچک

اگر سرمایه‌ی شما چند میلیون تومان است، `MAX_POSITION_PCT=5` ممکن است به سفارشی
کمتر از حداقل صرافی برسد. گزینه‌ها:

- `MAX_POSITION_PCT=10` و `MIN_TRADE_QUOTE=100000`
- `SYMBOL=ETHIRT` یا دارایی با قیمت واحد کوچک‌تر
- `MAX_TOTAL_POSITION_PCT` را هم متناسب بالا ببرید (مثلاً ۲۰)

هر تغییری را ابتدا در حالت `paper` چند روز اجرا و در `report` بررسی کنید.

## چرا بک‌تست ندارد؟

این نسخه عمداً ساده و قابل ممیزی نگه داشته شده است. برای بک‌تست، توابع
`build_snapshot` و `decide` خالص و بدون وابستگی به شبکه هستند؛ می‌توانید کندل‌های
تاریخی را از `fetch_candles` بگیرید، در فایل ذخیره کنید و روی آن‌ها حلقه بزنید.
هنگام بک‌تست، کارمزد (`FEE_PCT`) و اسلیپیج را حتماً لحاظ کنید.
